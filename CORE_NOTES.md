# Masked diffusion reconstruction

The only reference source is commit `3ff606831e48be8069cb42a2afffa666051d53fa` of the read-only `masked_reference` checkout, read using `git show`. Sources are `latent_diffusion/mdlm/models2/dit.py`, `latent_diffusion/mdlm/noise_schedule.py`, `latent_diffusion/mdlm/diffusion.py` and `latent_diffusion/blockwise_baselines/mdlm_prefix_block_noisy_past_512_rw128/{generate.py,tools/prefix_block_diffusion.py}`.

## Architecture and portability

The denoiser preserves the original DiT design: Kaiming-initialized token embeddings, 256-frequency sinusoidal timestep mapping through a two-layer SiLU network, SiLU conditioning, learned scale-only LayerNorm, rotary query/key positions, bidirectional attention, adaptive normalization with six modulation channels, gated attention and 4× GELU(tanh) MLP residuals, and a zero-initialized modulated output head. Adaptive modulation layers are also zero-initialized. Default reconstructed configuration is hidden size 512, 8 blocks, 8 heads, conditioning width 128, dropout .1, time conditioning disabled, 512 regular codes plus MASK at index 512, and a 16-code current block. These explicit settings do not establish the unavailable historical trained configuration or exact reproduction of trained quality.

`einops` reshaping is replaced by tensor reshape/transpose, optional FlashAttention by PyTorch SDPA, and Hub/OmegaConf/Lightning/JIT-global-switch machinery by plain PyTorch/dataclasses. SDPA dropout follows the reference's PyTorch fallback (training dropout .1); the original FlashAttention branch used attention dropout zero, so that backend difference is an explicit limitation. Normalization accumulates in fp32 and then returns the input dtype for mixed-precision portability. CUDA autocast is controlled by the training caller, not enabled implicitly inside the model.

Hard prefix lookup and soft prefix matrix multiplication are equivalent for one-hot distributions and preserve gradients for soft inputs. This is the intended probability-embedding extension of the reference prefix helper, whose call into the unmodified integer embedding did not itself implement soft projection. No `[B,P,K+1]` one-hot allocation is needed for hard prefixes. Positions cover the supplied past plus current block; no prefix compression occurs. Optional activation checkpointing wraps only DiT blocks, only while training with gradients enabled.

## Process, loss and corrections

The absorbing forward process independently replaces current regular codes with MASK with probability `(1-noise_eps)*t`. The reference log-linear schedule is `sigma=-log(1-(1-noise_eps)*t)`. Its continuous diffusion weight `sigma'/expm1(sigma)` is exactly `1/t`. The implementation computes the equivalent survival probability `(1-t)+noise_eps*t`, retaining a finite endpoint for settings such as `noise_eps=1e-8` where subtractive float32 arithmetic previously rounded survival to zero. For times at or below `.5`, sigma uses the algebraically equivalent `log1p` expression to retain small positive noise levels even when float32 survival rounds to one; later times use the stable survival logarithm. Half/bfloat16 schedule inputs are promoted to float32. Noise/time epsilons below the float32 normal minimum use float64 schedule arithmetic, sampled times and sampler grids; ordinary/default settings keep their float32 time precision and generation RNG behavior. Epsilons must be finite and at least the float64 normal minimum (`sys.float_info.min`), because smaller values cannot reliably support reciprocal schedule/time weights; unsupported values are explicitly rejected, never clipped. These precision changes do not alter the mathematical schedule.

Training times use the reference per-example antithetic strata. Loss is masked current-code NLL, weighted by `1/t`, averaged over all batch target positions. The denominator is total target length, never number of masked sites. All-unmasked draws produce a differentiable zero without multiplying zero by infinities.

Only training may randomly replace past codes; replacements are drawn from regular code IDs. Validation disables both replacement and smoothing even if the caller previously used training mode. Optional past-label smoothing distributes mass over regular codes only, keeping MASK probability zero. The historical helper included MASK among replacement/smoothing possibilities; the corrected baseline excludes it. The baseline experiment can set corruption .2; the default loss dataclass is .1 and the experiment configuration supplies the selected value.

SUBS sets predicted MASK probability to zero and every revealed current code to an exact point mass. Sampler updates preserve revealed codes and fixed past. `ddpm` and `ddpm_cache` use the same log-linear categorical transition. Cache reuse requires both unchanged current state and disabled time conditioning. This caches predicted categorical probabilities, not past KV states: past representations attend bidirectionally to current tokens in the original architecture and change when the current state changes. Terminal cleanup argmax replaces only remaining MASK sites. Output cannot contain MASK.

## Candidate scoring and state

All candidates, scoring, cleanup and optional refinement execute in a single EMA/eval/no-grad scope. The scope independently saves each module's mode and live parameter copies; exceptions and nested scopes restore the enclosing exact state. EMA checkpoints contain named tensors, numbers and dicts, validate names/shapes before mutation, and return copies. There is no shared mutable EMA backup slot.

Generation and scoring have separate local device RNGs. The entire candidate pool is generated before scoring. Midpoint time strata and corruption masks are generated once per block and shared across its candidates. The corrected score divides masked weighted NLL by target length. `legacy_mask_count` explicitly preserves the reference masked-count denominator and its forcing of position zero when a whole score draw is empty. Zero-mask draws in the corrected score contribute zero; they are not forced. Scoring uses temperature 1; sampling temperature applies only to regular-code logits. Candidate ordering is stable and ties choose the first candidate. The implementation reranks the first block too when candidates > 1; the historical default generator drew its first block once. Scores compare conditional diffusion loss; no claim is made that they measure actual text quality.

Default sampling retains the full generated past. `max_context_codes=112` explicitly enables the legacy truncation ablation. `num_codes` counts the total length including a supplied prefix, which may be any valid length. The last generated block can be shorter than 16. A 2048-code path supplies 2032 past codes to the final 16-code block. Soft/hard prefix mixtures are optional and start a supplied prefix as a hard one-hot distribution. The selected block's raw final probabilities are computed only if soft propagation is requested. Full context still has quadratic attention cost, and training exposure to long prefixes is necessary to assess long-text quality.

Optional `refinement_rounds` implements **experimental current-block masked leave-one-out refinement**. Each round probes every current position with that position replaced by MASK for all batch rows, using the same fixed past and all other current codes as revealed context. The confidence is the regular-channel conditional probability of the position's original code under this masked input, at temperature 1. Raw predictions at revealed sites are not used for selection: those predictions do not receive the masked-target training objective. Probe time corresponds to one expected mask, `1/((1-noise_eps)*block_length)`, bounded by one and the configured minimum sampling time; it is a chosen heuristic, not a calibrated probability of correctness.

The least-confident `ceil(block_length*refinement_fraction)` positions are remasked, with at least one chosen. Resampling begins at the actual selected fraction of current positions, so small requested fractions do not create a time grid inconsistent with the minimum one-position remask. The remaining current codes stay anchored, and previously generated past stays fixed. Every batch forward counts once in `refinement_nfe`: exactly `block_length` masked confidence probes per round, plus its actual DDPM/cleanup calls. Cache savings apply only to the resampling phase. Stats label the method `experimental_current_block_masked_leave_one_out`; refinement remains disabled by default. This is not a verified ReMDM implementation, and no quality gain is claimed. Beam search, overlap/carryover generation, analytic/SEDD/D3PM processes and historical Lightning checkpoint migration are not implemented. No hidden fallback to those methods occurs.

NFE statistics count actual model forward calls (a batched call counts as one), with separate generation/scoring/refinement totals, plus measured wall time, returned length and maximum supplied prefix. CUDA timing is synchronized at entry and exit; performance has not been measured on GPU.

## Verification status

Tests were written before production implementation for DiT gradient/one-hot equivalence, zero initialization and time conditioning, invalid inputs, SUBS carryover, log-linear math, loss normalization and zero-mask gradients, regular-only past corruption, EMA state copies, mixed-mode and exception/nesting restoration, sampler seed/global-RNG behavior, cached/uncached agreement, scoring RNG independence, shared candidate pools, full-prefix access, real DiT 2032-prefix shape, refinement anchoring, and invalid configurations.

A pytest invocation was started before the user's explicit instruction to perform no execution. At that time the core module had not been created, and the observed output contained missing-implementation errors; there was no completed green test run. **Runtime tests, model execution, training and generation after that instruction have not been run.** Only source parsing/compilation checks are permitted now; the tests remain a deliverable for a later authorized environment. No dataset, checkpoint download or external service was used.

Following independent static review, additional regression tests were written without execution for float32/fp16/bfloat16 finite tiny-epsilon endpoints, tiny positive times retaining nonzero sigma and the analytic weight, float64 promotion for sub-float32 epsilon settings, explicit rejection below the supported float64 range, and masked leave-one-out confidence selection. The confidence regression deliberately assigns misleading logits at revealed positions and independently specified conditional probabilities `.8/.2/.6` at the actual masked targets; it checks one-position masking, immutable current/past inputs, selection of the lowest conditional probability, retained anchors and exact NFE accounting including possible terminal cleanup. These tests remain **NOT RUN**; syntax checks do not establish a passing runtime.
